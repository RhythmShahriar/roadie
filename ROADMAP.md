# Roadmap

Roadie 1.0 is in development. These are left out of 1.0 on purpose and come later.

## Not in 1.0

- Copying files and uploads. The plan prints an rsync exclude list instead.
- Editing web server config. Basic auth is a printed snippet.
- Object caches and search indexes (Redis, Algolia, ElasticPress).
- Fleet runs over `sites.yaml` and scheduled refresh with notifications (planned for 1.1).
- mydumper folders.
- `pg_dump -Fc` and `-Fd` archives.
- Binary backups (xtrabackup).
- `.wpress` and Duplicator archives.
- Drupal, Magento, Shopify and MongoDB.
- An in-place `UPDATE` mode for `prepare`.
- `--jsonl` progress events.
