# key.unknown-env: a provider key Roadie can't classify (medium)

What: A key of a known provider that Roadie can't tell is live or test.

Why it matters: It might be live. Roadie never changes a key it can't
classify.

What Roadie does: It is reported and left as it is.

By hand: Check the key at the provider; replace a live one with a test key.
